# Meta Horizon Link Doctor v1.0.0

**🇧🇷 [Português](#-português) · 🇺🇸 [English](#-english)**

---

## 🇧🇷 Português

Ferramenta que **detecta e corrige a causa real** da falha de instalação do
**Meta Horizon Link** no Windows 10/11 — aquela em que o instalador baixa tudo,
chega ao fim e desfaz tudo sem explicar o motivo.

### O que ela resolve

- Política do Windows que bloqueia drivers da classe **Display**
  (`DenyDeviceClasses` → `0xE0000248`) — a causa mais comum
- `OVRService` apontando para uma instalação movida ou quebrada
- Pastas de instalação antigas (Downloads, Desktop, outros discos)
- Acúmulo de crash dumps do OVRServer (que travava o cliente na tela de carregamento)

### Como usar

1. Baixe o `MetaHorizonLinkDoctor.exe` abaixo
2. Aceite o UAC e clique em **Corrigir problemas**
3. Rode o instalador oficial da Meta

Tudo é reversível: backup `.reg` automático em `%ProgramData%\MetaHorizonLinkDoctor`
e pastas apenas renomeadas (`*.old-<data>`). Nada é apagado.

### Requisitos

- Windows 10 (2004 ou superior) ou Windows 11
- Nenhuma instalação extra: roda no .NET Framework 4.8 que já vem no sistema
- ~100 KB de disco

### Verificação de integridade

Confira o `SHA256SUMS` anexado:

```
Get-FileHash .\MetaHorizonLinkDoctor.exe -Algorithm SHA256
```

O executável não é assinado, então o Windows pode exibir *"O Windows protegeu o
seu PC"* → **Mais informações** → **Executar assim mesmo**. O código-fonte é
público e pode ser compilado localmente com `build.ps1`.

- Causa raiz com todas as evidências de log: [docs/CAUSA-RAIZ.md](https://github.com/akumanfrancisco/meta-horizon-link-doctor/blob/main/docs/CAUSA-RAIZ.md)
- Diagnóstico somente-leitura para anexar em issues: [scripts/diagnose.ps1](https://github.com/akumanfrancisco/meta-horizon-link-doctor/blob/main/scripts/diagnose.ps1)

## 🇺🇸 English

A tool that **finds and fixes the real cause** of the **Meta Horizon Link**
install failure on Windows 10/11 — the one where the installer downloads
everything, reaches the end, and rolls everything back without a useful message.

### What it fixes

- A Windows policy blocking **Display class** driver installation
  (`DenyDeviceClasses` → `0xE0000248`) — the most common cause
- `OVRService` pointing to a moved or broken installation
- Leftover install folders (Downloads, Desktop, other drives)
- OVRServer crash dump pileup (which kept the client stuck on the splash screen)

### How to use

1. Download `MetaHorizonLinkDoctor.exe` below
2. Accept the UAC prompt and click **Fix problems**
3. Run the official Meta installer

Everything is reversible: automatic `.reg` backup in
`%ProgramData%\MetaHorizonLinkDoctor`, folders are only renamed
(`*.old-<date>`). Nothing is deleted.

### Requirements

- Windows 10 (2004 or newer) or Windows 11
- No extra install: runs on the .NET Framework 4.8 already included in Windows
- ~100 KB of disk space

### Integrity check

Verify the attached `SHA256SUMS`:

```
Get-FileHash .\MetaHorizonLinkDoctor.exe -Algorithm SHA256
```

The executable is not code-signed, so Windows may show *"Windows protected your
PC"* → **More info** → **Run anyway**. The source code is public and you can
build it yourself with `build.ps1`.
